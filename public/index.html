Outgoing IP — proxies (optional)

When you press Verify, MailCheck first hunts for free SOCKS5 proxies that pass port 25, then runs the checks through them. When one proxy stops answering, it switches to the next by itself. No searching, no copy-paste. This ignores the manual proxy fields below.

Or set one proxy by hand. By default checks go out from this machine's IP; through a SOCKS5 proxy, the mail server sees the proxy's IP instead.

Leave the host empty to use your own IP. The proxy is used only for the mailbox probes, nothing else.

    How it works: syntax → disposable check → MX lookup → catch-all probe → SMTP RCPT TO probe. The connection is closed before DATA, so no email is ever sent. Statuses: valid (mailbox confirmed), invalid (rejected or no mail server), risky (domain accepts everything — the mailbox cannot be confirmed), unknown (server unreachable, greylisted or timed out), disposable (temporary provider).

    Note: some providers (notably Gmail) block or rate-limit mailbox probes from residential IPs. If a lot of results come back “unknown”, run from a server/VPS IP or through the proxy option above.
